How These Numbers Are Defined

  • Total Authorizations — rows matching the current Type, Status and date filters. Type is matched case-insensitively (the export mixes Appointment with DIAGNOSTIC).
  • Touched by RPA — distinct rows where RC Assigned contains svc-quickbase or Bot Run Fail Date is populated. Rows with both are counted once.
  • RPA Success Rate — rows where RC Assigned contains svc-quickbase, over rows touched by RPA. A row with both a fail date and a bot assignment counts as a success after retry.
  • Date Presets are anchored to the latest date in the export, not to today, so a stale file still shows a populated window.
  • Failure reasons are normalized into categories; member and authorization identifiers present in the raw text are stripped before publishing, and only aggregate counts are shipped.
